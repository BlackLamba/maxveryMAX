# Идеи для хакатона MAX

## Кейс

> Придумать сервис для афиш событий, волонтёрства, туризма или спорта — от поиска до покупки билетов.

Необходимо разработать чат-бота или мини-приложение для мессенджера MAX, которое помогает пользователю найти подходящее мероприятие или активность и пройти путь от выбора до участия.

---

# Концепция №1 — MAX.EVENTS

## «Куда сегодня?»

Умная персональная афиша мероприятий прямо внутри MAX.

Пользователь не ищет события по десяткам сайтов. Он просто рассказывает боту, чем хочет заняться:

> «Хочу куда-нибудь сходить вечером с девушкой, бюджет до 3000 ₽»

или:

> «Что интересного будет в Ярославле на выходных?»

Сервис анализирует запрос и предлагает подходящие мероприятия.

### Основной сценарий

1. Пользователь открывает бота.
2. Указывает город или разрешает определить его автоматически.
3. Выбирает интересы:
   - концерты;
   - кино;
   - театр;
   - спорт;
   - выставки;
   - фестивали;
   - туризм;
   - развлечения;
   - волонтёрство.
4. Бот формирует персональную афишу.
5. Пользователь открывает карточку события.
6. Видит:
   - дату;
   - время;
   - место;
   - стоимость;
   - описание;
   - участников;
   - рейтинг;
   - расстояние;
   - количество свободных мест.
7. Покупает билет или записывается на мероприятие.
8. Получает билет прямо в MAX.
9. Бот напоминает о мероприятии.

---

## Главная фишка

### Поиск не по фильтрам, а обычным языком

Вместо:

> Город → дата → категория → цена → возраст

пользователь пишет:

> «Хочу активный отдых в субботу, недалеко от города, желательно на природе и до 2000 рублей».

Система сама превращает запрос в параметры поиска.

# Концепция №2 — MAX.TRIP

## «Собери мне выходные»

Сервис для поиска мероприятий и туристических активностей с автоматическим составлением маршрута.

Пользователь говорит:

> «Я в Ярославле на два дня. Хочу посмотреть город, сходить куда-нибудь вечером и съездить на природу».

Сервис формирует готовый план.

### Пример

**Суббота**

09:30 — завтрак  
10:30 — экскурсия по историческому центру  
13:00 — обед  
15:00 — музей  
18:30 — концерт  
21:00 — ресторан

**Воскресенье**

09:00 — выезд на туристический маршрут  
13:00 — экскурсия  
16:00 — возвращение в город

### Что умеет сервис

- искать достопримечательности;
- искать экскурсии;
- искать спортивные активности;
- искать фестивали;
- искать концерты;
- покупать билеты;
- строить маршрут;
- учитывать бюджет;
- учитывать свободное время;
- учитывать расстояния;
- объединять несколько событий в один маршрут.

# Концепция №3 — MAX.TEAM

## «Найди компанию»

Сервис для поиска людей, с которыми можно сходить на мероприятие.

Проблема:

> «Я хочу сходить на концерт, но никто из друзей не может».

Пользователь выбирает мероприятие, а сервис предлагает людей, которые тоже собираются туда.

### Сценарий

**Концерт**

21 сентября  
Ярославль  
Рок

> На это мероприятие собираются ещё 18 пользователей.

Можно выбрать:

- «Иду один»
- «Хочу компанию»
- «Ищу друзей»
- «Ищу попутчиков»

После этого сервис объединяет людей в групповой чат MAX.

### Дополнительная возможность

Можно искать компанию не только для мероприятий:

- походов;
- велосипедных поездок;
- футбола;
- настольных игр;
- путешествий;
- фестивалей;
- волонтёрских мероприятий.

# Концепция №4 — MAX.VOLUNTEER

## «Помоги рядом»

Агрегатор волонтёрских мероприятий.

Пользователь открывает приложение и видит:

> 12 возможностей помочь сегодня рядом с вами

Например:

### Помочь приюту

2,4 км  
Сегодня, 18:00–21:00  
Нужно ещё 4 человека

### Посадить деревья

7 км  
Суббота, 10:00  
Нужно ещё 12 человек

### Помочь на спортивном мероприятии

1,8 км  
Воскресенье, 08:00  
Нужно ещё 8 человек

Пользователь нажимает:

> **Участвовать**

и получает всю необходимую информацию.

# Концепция №5 — MAX.SPORT

## «Спорт рядом»

Сервис поиска спортивных мероприятий и активностей.

Пользователь может найти:

- соревнования;
- забеги;
- турниры;
- футбольные матчи;
- хоккей;
- баскетбол;
- тренировки;
- спортивные секции;
- массовые спортивные мероприятия.

### Особенность

Сервис может подбирать мероприятия исходя из уровня пользователя.

Например:

> «Я никогда не бегал. Хочу попробовать забег на выходных».

Бот не предложит марафон.

Он предложит:

- Fun Run — 3 км
- Любительский забег — 5 км
- Благотворительный забег — 2 км

# MAX.GO

## «Найди. Собери. Забронируй. Иди.»

Единая платформа активностей внутри MAX.

Пользователь не выбирает категорию заранее.

Он просто говорит:

> «У меня свободный вечер в пятницу. Хочу куда-нибудь сходить, бюджет 3000 рублей».

MAX.GO предлагает варианты:

- Концерт — 1800 ₽
- Театр — 2200 ₽
- Картинг — 1500 ₽
- Выставка + мастер-класс — 1200 ₽
- Ночной туристический маршрут — 1000 ₽

---

# Умный подбор

Система учитывает:

- интересы пользователя;
- бюджет;
- свободное время;
- расстояние;
- компанию;
- погоду;
- возрастные ограничения;
- уже купленные билеты;
- историю посещений.

Со временем рекомендации становятся персональными.

# Социальный сценарий

Особенно интересно использовать возможности мессенджера.

Пользователь может отправить другу:

> «Пойдём сюда?»

Друг нажимает:

> **Иду**

После этого создаётся групповой чат мероприятия.

В нём можно:

- обсудить встречу;
- поделиться билетом;
- увидеть участников;
- договориться о месте встречи;
- построить общий маршрут.

# Почему именно MAX?

MAX используется не просто как место запуска приложения.

Мессенджер становится частью продукта:

1. Уведомления
2. Электронные билеты
3. Групповые чаты
4. Отправка событий друзьям
5. Чат-бот
6. Геолокация
7. Покупка билетов
8. Напоминания

Таким образом пользователь не покидает MAX на всём пути:

**Поиск → выбор → покупка → общение → посещение**

# MVP

Для хакатона не обязательно реализовывать всю платформу.

Достаточно сделать:

### 1. Главный экран

- поиск;
- категории;
- рекомендации;
- ближайшие события.

### 2. Поиск

Пользователь пишет:

> «Куда сходить вечером в пятницу?»

### 3. Каталог

Карточки мероприятий.

### 4. Страница мероприятия

Подробная информация + кнопка покупки.

### 5. Билет

После покупки пользователь получает электронный билет.

### 6. Уведомления

Напоминание:

> «Через 2 часа начинается ваше мероприятие».
