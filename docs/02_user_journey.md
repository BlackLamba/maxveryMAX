# 02. Карта пути пользователя и сценарии использования

## 1. Основной принцип

Пользователь не должен воспринимать продукт как ещё один каталог. Главная ценность:

> **«Скажи, чем хочешь заняться — сервис быстро найдёт реальные подходящие события и доведёт до покупки.»**

Основной UI — Mini App. Бот используется как вход, уведомления и напоминания.

## 2. Основная карта пользователя

```text
Пользователь видит/получает ссылку
            ↓
       MAX Bot
            ↓
      Открыть афишу
            ↓
       MAX Mini App
            ↓
      Выбор города
            ↓
  Выбор интересов (опционально)
            ↓
      Главный экран
            ↓
 ┌──────────┼───────────┐
 ▼          ▼           ▼
Лента     Поиск      «Подбери»
 │          │           │
 ▼          ▼           ▼
Карточка → детали → купить
 │
 ▼
Избранное
 │
 ▼
Уведомление от бота
 │
 ▼
Возврат в Mini App
```

## 3. Первый запуск

### Экран

```text
Добро пожаловать!

📍 Ваш город: [Москва ▼]

Что вам интересно?
[🎵 Музыка] [🎭 Театр]
[😂 Стендап] [🎨 Искусство]
[⚽ Спорт] [🎮 Игры]

[Показать мероприятия]
```

Геолокация не должна быть обязательной. Город задаётся пользователем вручную. Геолокация — отдельная функция «рядом со мной».

## 4. Главный экран

Ключевые элементы:

```text

[🔎 Что вы хотите найти?]

[Сегодня] [Неделя] [Выбрать]

✨ Для вас

[карточка мероприятия]
[карточка мероприятия]
[карточка мероприятия]

[🏠 Афиша] [♥ Избранное] [👤 Профиль]
```

## 5. Важные кнопки

### Город

Открывает:
- список популярных городов;
- поиск города;
- текущий выбранный город.

### Поиск

Поддерживает обычный поиск и естественный язык.

Примеры:
- `рок-концерты в Москве`;
- `куда сходить в субботу`;
- `что-нибудь до 2000 рублей вечером`;
- `что посмотреть в Казани на выходных`.

### Фильтры

MVP:
- дата;
- категория;
- цена;
- бесплатные;
- возраст.

P1:
- расстояние;
- время начала;
- теги/жанры.

### Подробнее

Карточка показывает:
- изображение;
- название;
- дату и время;
- место;
- цену;
- описание;
- теги;
- источник;
- [♥ Сохранить];
- [🎟 Купить];
- [🗺 На карте];
- [↗ Поделиться].

## 6. Сценарий: «Хочу куда-нибудь сходить»

```text
Открыть Mini App
   ↓
Выбрать город
   ↓
Нажать «Для вас»
   ↓
Получить подборку
   ↓
Открыть событие
   ↓
Сохранить / купить
```

## 7. Сценарий: поиск естественным языком

Пользователь вводит:

> хочу весёлое мероприятие в Москве в субботу до 2500 рублей

Система превращает запрос в структуру:

```json
{
  "city": "Москва",
  "date": "Saturday",
  "price_max": 2500,
  "intent": "entertainment"
}
```

Затем выполняется обычный поиск + ranking.

## 8. Сценарий: поездка в другой город

```text
Москва
  ↓
[Изменить город]
  ↓
Санкт-Петербург
  ↓
[Мероприятия]
```

Текущий город не меняется навсегда: можно использовать «Город поездки» как временный контекст.

## 9. Сценарий: «рядом со мной»

1. Пользователь нажимает «Рядом со мной».
2. Mini App запрашивает геолокацию.
3. Backend получает координаты.
4. События сортируются по расстоянию.

Геолокация — дополнительная возможность, не обязательный onboarding.

## 10. Сценарий: избранное + бот

```text
Пользователь
    ↓
♥ Сохранить
    ↓
Backend
    ↓
Favorites
    ↓
Бот
    ↓
"Завтра в 20:00 начинается мероприятие, которое вы сохранили"
```

## 11. Сценарий: новые подходящие события

Пользователь настраивает:

```text
Москва
Музыка + стендап
До 3000 ₽
2 уведомления в неделю
```

Worker периодически проверяет новые события и отправляет уведомление только при достаточной релевантности.

## 12. Сценарий: покупка

```text
Event Detail
    ↓
[🎟 Купить билет]
    ↓
Purchase URL / партнёрская страница
```

В MVP не обязательно строить полноценный checkout внутри Mini App.

## 13. Нижняя навигация

Рекомендуется:

```text
🏠 Афиша | ♥ Избранное | 👤 Профиль
```

Профиль содержит:
- город;
- интересы;
- настройки уведомлений.

## 14. UX-принцип

Количество обязательных действий на старте должно быть минимальным.

Пользователь должен получить первые реальные мероприятия максимум после:
1. выбора города;
2. необязательного выбора интересов.

## 15. Главная демонстрация на хакатоне

Идеальный demo flow:

```text
Открываем MAX
→ Mini App
→ Москва
→ «Хочу что-нибудь весёлое
   на субботу до 2500»
→ AI/NLP разбирает запрос
→ 3–5 реальных событий
→ открываем событие
→ сохраняем
→ показываем уведомление от бота
→ переходим к покупке
```

## 16. Что пользователь должен почувствовать

Не:
> «Я посмотрел каталог.»

А:
> **«Я за несколько секунд понял, куда могу сходить.»**
